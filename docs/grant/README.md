## How to create PDFs (Windows)

1. Open the `.html` file in **Chrome** or **Edge**.
2. Press **Ctrl+P** → **Save as PDF**.
3. **Company profile:** Paper = A4, Portrait, Margins = Default.
4. **Pitch deck:** Paper = A4, **Landscape**, enable **Background graphics**.
5. Save as `AdharaEdu-Company-Profile.pdf` and `AdharaEdu-Pitch-Deck.pdf` (each should be under 10 MB).
