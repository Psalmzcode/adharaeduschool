1. Executive Summary

AdharaEdu provides structured technology education designed to equip secondary school students with practical digital skills required for academic success, university preparation, and future careers. The programme is delivered within a school’s existing computer laboratory using trained tutors, structured learning materials, and measurable outcomes.

The programme is organised into three progressive tracks: Digital Foundations, Introduction to Programming, and Advanced Tech & Career Readiness. A digital platform supports enrollment, attendance, assessments, certificates, payments, and reporting for schools, tutors, students, and parents.

2. Programme Structure

Track 1 — Digital Foundations

Students learn core computer literacy including file management, typing skills, document creation with Microsoft Word, spreadsheet fundamentals with Excel, and responsible internet usage.

Track 2 — Introduction to Programming

Students learn programming logic using Scratch before progressing to HTML and CSS to build structured and styled multi-page websites.

Track 3 — Advanced Tech & Career Readiness

Students expand their skills with JavaScript and Python programming while building a personal project portfolio.

3. Programme Delivery

The programme is delivered within each school’s timetable structure. Session duration and frequency depend on the periods allocated by the school. Lessons combine demonstrations, guided practice, and hands-on student projects.

AdharaEdu deploys trained tutors, provides structured learning materials, and gives schools access to an online dashboard for administrators, tutors, students, and parents — enabling real-time visibility into attendance, progress, and results.

4. Student Assessment

Students complete end-of-term assessments consisting of a practical task and a short theory component. Successful students receive AdharaEdu Certificates of Completion documenting their skill development. Certificates are verifiable online (QR code) for schools and partners.

The platform also supports computer-based testing (CBT), assignments, and practical assessments throughout the term.
